# UNIV-ELEARNING

Portfolio fork of the collaborative `UNIV-ELEARNING` project originally hosted at:
https://github.com/Preciousuche327/UNIV-ELEARNING

## Project Overview

UNIV-ELEARNING is a PHP-based university e-learning platform. The project includes student and instructor workflows for course browsing, course content, quizzes, authentication, database setup, and deployment-oriented configuration.

## My Role

I contributed as a collaborator on the team project, focusing on UI/UX improvements, app consistency fixes, course catalog behavior, authentication cleanup, and database/deployment support.

## My Contributions

Public Git history links `Minj21` / Amin Jimoh to 7 commits in the original repository. My contribution evidence includes:

- Added a UI/UX improvement guide documenting interface enhancements and polish recommendations.
- Added a reusable confirmation modal component for destructive actions in `app/views/partials/modal-confirm.php`.
- Added an enhanced stylesheet in `public/css/style-enhanced.css`.
